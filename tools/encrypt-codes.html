hide keypad codes

Turns your secret codes into scrambled data that can't be read in the page source. This page runs only in your browser; nothing you type here is sent anywhere.

Steps
  1. Open this file from your own computer (double-click tools/encrypt-codes.html), not from the live website.
  2. Write your secret codes below, one { ... } block each, same format as config/keypad-codes.js (code, say, image, caption, message, download, downloadText, sound, link, newTab, title, keepOpen).
  3. Press hide them, then download keypad-secrets.js. Put that file in your config/ folder (replace the old one), commit and push.
  4. Keep your plain list private. Save the text from the box below in a file called private/secret-codes.txt. The private/ folder is ignored by git, so it never gets uploaded. Next time you add a code, paste the whole list back in here and run it again.
Good to know
  • The code is the password. Short or common codes can be guessed by a computer in seconds, whatever the encryption: any number under about 9 digits, any single word. Use phrases only your friends would know: several words, an inside joke, a nickname plus a date.
  • What the code does is hidden too (the message, which picture, the file name), but a picture or download that sits in your media/ folder is still a public file in your public GitHub repo. Give it an unguessable name (like unlisted-8f3k2.png), or use message / downloadText, which live fully inside the scrambled data.
  • Hidden codes can't use run (custom JavaScript) or auto. Use config/keypad-codes.js for those.
  • Hidden codes take a moment to check (about a quarter of a second) after you press enter. That slowness is what makes guessing hard.
